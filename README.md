# Executive Research Platform

A curated collection of strategic frameworks, research insights, and business ideas designed to support executive decision-making.

## Features

- **Strategic Frameworks**: Deep-dive into proven frameworks like Porter's Five Forces, VRIO, Blue Ocean Strategy, and more
- **Research Library**: Case studies, market analysis, and data-driven insights
- **Ideas & Perspectives**: Articles on strategy, leadership, innovation, and organizational dynamics
- **Clean, Modern Design**: Built with Astro and Tailwind CSS for fast performance and excellent user experience

## Project Structure

```
src/
├── components/          # Reusable UI components
├── layouts/             # Page layouts (Base, Framework)
├── pages/               # Dynamic pages
│   ├── index.astro      # Homepage
│   ├── frameworks/      # Framework pages
│   ├── ideas/           # Ideas collection
│   └── research/        # Research collection
└── styles/              # Global styles
```

## Getting Started

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The site will be available at `http://localhost:3000`

### Build

```bash
npm run build
```

Output will be in the `dist/` directory.
